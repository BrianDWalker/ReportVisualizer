Results Visualizer for DBeaver

This address is a DBeaver/Eclipse p2 update site containing only the latest stable Results Visualizer release.

  1. In DBeaver, open Help > Install New Software.
  2. Add https://briandwalker.github.io/ReportVisualizer/.
  3. Select Results Visualizer for DBeaver, complete the wizard, and restart DBeaver.
